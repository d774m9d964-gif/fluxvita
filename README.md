# FluxVita

Demonstração estática do projeto FluxVita para registro e acompanhamento de medições da água.

Acesse a homepage e o painel pelo GitHub Pages deste repositório. Os registros são manuais e ficam somente no navegador do visitante, sem sincronização, conexão automática com sensores ou cobrança. A proposta Premium está em validação. Os dados e relatórios não substituem análises laboratoriais ou avaliações especializadas.

Este repositório contém os arquivos compilados para publicação. A equipe mantém o projeto de desenvolvimento separadamente. As fotografias e a identidade visual pertencem ao material fornecido pela equipe.
